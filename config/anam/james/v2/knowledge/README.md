# James v2 Knowledge Bundle

This folder is the proposed public-safe allowlist for James's Anam RAG tool. Only the six numbered Markdown documents are eligible for upload. The release is not yet synchronized or live; see `knowledge-manifest.json` and `runtime-release-manifest.json`.

The bundle deliberately excludes visitor data, transcripts, Tavus materials, legal guidance, and unsupported firm claims. The current Anam account snapshot reports provider zero-data-retention disabled, so the AI must not solicit personal or detailed case information and must not describe the conversation as private.
