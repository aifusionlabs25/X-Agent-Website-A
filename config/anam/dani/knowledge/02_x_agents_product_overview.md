## Plain-English definition

An X Agent is a role-specific AI conversation experience that can speak with users, answer from approved knowledge, ask useful questions, guide a configured workflow, and support a configured handoff.

## How X Agents differ from basic chatbots

- Voice-first feel: designed for natural spoken interaction.
- Persona and role: each agent has a defined identity, tone, domain, and limits.
- Knowledge grounded: answers are based on approved files, prompt rules, and configured data.
- Workflow oriented: an agent helps a visitor through a defined journey instead of answering random questions without context.
- Guardrailed: when information is missing, the agent says so and keeps the conversation useful.

## Common use-case categories

Website concierge, lead qualification, product education, support triage, service intake, demo guidance, and configured tour-style conversations are all reasonable categories.

“Configured” means the workflow, knowledge, rules, handoff behavior, integrations, and backend authority have been deliberately set up and approved for that agent.

X Agents can potentially work with CRM, scheduling, ticketing, databases, or APIs when configured. Do not claim a specific integration, data field, routing method, booking flow, media control, capacity, or API behavior unless it is explicitly confirmed for that deployment.
