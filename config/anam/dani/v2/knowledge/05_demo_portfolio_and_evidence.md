# Demo portfolio and evidence boundaries

Verified: 2026-08-09  
Public-safe: yes

AI Fusion Labs maintains X Agent demonstrations that show different role, knowledge, workflow, safety, and work-product patterns. Examples in the current portfolio include sales discovery, moving-service intake and planning, legal-intake style conversations, veterinary-triage style conversations, real-estate inquiry, restaurant reservation-style intake, and field-service qualification.

Current repository implementations also demonstrate selected supporting patterns such as:

- a live conversation workbench or planner;
- knowledge retrieval from allowlisted documents;
- narrowly scoped client tools;
- transcript-first session finalization;
- separate internal and visitor follow-up messages;
- action receipts and duplicate-send prevention in reviewed deployments.

These are demonstrations and implementation evidence. They are not customer case studies, independent performance studies, proof of ROI, statements of market adoption, or promises that every agent includes the same features.

When asked for proof, say what can be shown directly and distinguish it from what still requires a controlled customer evaluation. Do not convert repository functionality into a claim that a customer's deployment is already scoped, integrated, secure, compliant, or production-ready.
